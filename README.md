# هزارتو

وب‌سایت شرکت فناوری و نوآوری شناخت هزارتو. یک صفحه‌ی فارسی و راست‌چین که با کامپوننت‌های [وایب‌فارسی](https://vibefarsi.ir/components) ساخته شده است.

نسخه‌ی نمایشی روی گیت‌هاب پیجز بالا می‌آید و به سرور جدا نیاز ندارد.

## اجرا روی همین ماشین

```bash
npm install
npm run dev
```

سرور توسعه را روی پورت دلخواه هم می‌شود گرفت:

```bash
npx next dev --port 43123
```

## ساخت نسخه‌ی ایستا

برای ریشه‌ی دامنه:

```bash
npx next build
```

خروجی در پوشه‌ی `out` است.

برای گیت‌هاب پیجز این مخزن، مسیر پایه `/hezartoo` است:

```bash
NEXT_PUBLIC_BASE_PATH=/hezartoo npx next build
```

گردش‌کار `.github/workflows/pages.yml` همین ساخت را روی شاخه‌ی `main` انجام می‌دهد و به گیت‌هاب پیجز می‌فرستد.

## آنچه در صفحه هست

متن از معرفی عمومی شرکت و نشان هزارتو آمده است: واقعیت گسترده، هوش مصنوعی، طراحی بازی و علوم شناختی، پروژه‌های Neurotopia و Anavia، و رویداد «هوش؛ از انسان تا کامپیوتر» در اسفند ۱۴۰۳. فرم تماس پیام را ذخیره نمی‌کند؛ متن را برای فرستادن در اینستاگرام آماده می‌کند.
